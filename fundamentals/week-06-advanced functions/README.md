# Week 06 — Advanced Functions and Dictionaries

This week you expand your function toolkit and meet a brand new data structure.

You will use **built-in functions** beyond `len()`, learn what **methods** really
are, write **higher-order functions** with `map()` and `filter()`, define tiny
one-line functions with `lambda`, and store labelled data in **dictionaries**.

---

## What you will learn

- Common **built-in functions**: `len`, `sum`, `min`, `max`, `abs`, `round`, `sorted`, `type`
- What a **method** is and how it differs from a built-in function
- Useful list and string methods: `.append`, `.sort`, `.reverse`, `.upper`, `.split`, ...
- **`map()`** — apply a function to every item in a list
- **`filter()`** — keep only the items that match a condition
- **`lambda`** — write tiny anonymous functions inline
- **Dictionaries** — store data as key/value pairs
- Adding, updating, deleting keys, iterating with `.items()`, membership with `in`

## How to run the materials

**Option 3 — Plain script (press F5 in VS Code)**

```sh

```

> The folder name contains a space, so the paths must be wrapped in quotes
> in the terminal.
